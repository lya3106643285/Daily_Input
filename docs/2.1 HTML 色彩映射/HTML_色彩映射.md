# Lilac Moon · HTML 色彩映射 V1.0

状态：已定稿，2026-11-06 验收。源文件为 [theme.css](../../templates/css/theme.css)。本阶段仅提取颜色，边线宽度、字体及组件间距由相应的模板样式负责。

| 用途 | CSS 变量 | 色值 | 使用位置 |
|---|---|---|---|
| 月光白 | `--lm-page` | `#F7F8FF` | 整期页面、框外说明与出处背后的页面底色 |
| 浅紫月白 | `--lm-inset` | `#F9F6FF` | 栏目标题带 |
| 亮紫 | `--lm-decoration` | `#C7A6FF` | 栏目顶线、换篇细线、材料左竖线；自制图表生成时使用此色画柱条 |
| 纯黑 | `--lm-ink` | `#000000` | 标题、正文、说明文字 |
| 绯红 | `--lm-emphasis` | `#FF002B` | 基础色板的重点强调色，留给有明确强调语义的组件 |
| 冷蓝 | `--lm-auxiliary` | `#3794FF` | 基础色板的辅助信息色，供后续组件按需调用 |
| 材料浅紫底 | `--lm-media-surface` | `#F5F1FD` | 图、表、代码、引文的底板；与页面的亮度对比约 1.05∶1 |
| 材料出处链接 | `--lm-credit-link` | `#334990` | 沿用 1.6 右下出处链接的深蓝，链接保留下划线 |

## 使用方式

开发时先加载组件布局样式，再加载 theme.css。发布单文件 HTML 时，将主题文件全文内嵌在布局样式之后，离线阅读即可使用同一份配色。版式组件通过 CSS 变量复用颜色。自制柱状图用透明底，绘图时读取装饰色；已编码的 PNG 柱条需要重新出图才能换色。

本文的深蓝出处链接来自 1.6 实际样张，适用于材料旁的链接；1.4 文章来源区的链接继续继承该区文字颜色。绯红和冷蓝在这一阶段登记为基础色，后续按用途分配。
