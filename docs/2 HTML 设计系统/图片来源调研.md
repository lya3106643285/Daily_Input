## 每日一图的实测路径

1. **按主题查 ID。** 实测新版检索接口，关键词为 oxbow，带图，最多取五条。本次返回总计 11 条，第一页首条为 10497。日常可替换主题词与翻页，去除往期已刊的馆名和作品 ID，再查每条详情。检索走 v1.1，藏品详情走 v1。[本次检索](https://collectionapi.metmuseum.org/public/collection/v1.1/search?q=oxbow&hasImages=true&limit=5) · [官方 API 文档](https://metmuseum.github.io/)
2. **判断作品和图片权利。** 实测 10497 的详情返回 `isPublicDomain=true`、两个主图地址，以及作者 Thomas Cole 和创作年份 1836。馆藏页同时显示 Public Domain，馆方 Open Access 政策将相应图像以 CC0 开放。自动筛选要求该布尔值严格为真、主图地址存在，资料与馆藏页出现矛盾时转人工校对。馆方开放的目录数据还包括受保护的作品，因此只用数据字段或检索结果里的“有图”不足以放行图片。[作品详情 JSON](https://collectionapi.metmuseum.org/public/collection/v1/objects/10497) · [作品页](https://www.metmuseum.org/art/collection/search/10497) · [馆方开放政策](https://www.metmuseum.org/hubs/open-access)
3. **确认画面与刊用尺寸。** 实测网页尺寸 JPEG 为 599 × 409 像素、97,058 字节，可用作小图预览。原图文件头确认为 4000 × 2733 像素的 JPEG，服务器报告 3,053,431 字节。iPad 上若以整幅作品引导读者看细节，宜从详情给出的原图制作适合版心的较高清本地副本。图注可写「雷雨后的康涅狄格河谷，左侧的风暴云与右侧明亮的农田隔河相望」。材料出处可写「Thomas Cole，《牛轭湖》（The Oxbow），1836。大都会艺术博物馆，馆藏号 08.228，Open Access / CC0」，并链接馆藏页。中文简称是本刊用名。[网页尺寸 JPEG](https://images.metmuseum.org/CRDImages/ad/web-large/DP-12550-001.jpg) · [原图](https://images.metmuseum.org/CRDImages/ad/original/DP-12550-001.jpg) · [馆藏说明](https://www.metmuseum.org/art/collection/search/10497)

**备选来源。** 克利夫兰艺术博物馆支持按 `cc0` 和 `has_image=1` 搜索，逐条要求 `share_license_status == "CC0"` 且 `images.web.url` 有值。留存作品页、作者、标题、许可和原始图址。这是馆方文档支持的备选路径，本次从运行环境请求检索接口得到 HTTP 403，尚未在此环境验证完整取图。[馆方 API 与字段说明](https://openaccess-api.clevelandart.org/) · [馆方开放政策](https://www.clevelandart.org/open-access)

## 离线出版与缺图处理

入选文件随期放入 `assets/`。原稿写相对路径、替代文本、图注和材料出处，素材记录分别保留作品页、文件地址、授权依据及核验日期。打包时按文件实际格式编码为 data URI 写入 HTML，作者、作品名和许可随图显示。离线打开成品时应能解码并看到图片，点击外部出处才需要网络。[项目媒体协议](<../1.6 媒体内容协议/Media_Asset_Spec_V1.0.md>) · [HTML 设计系统](HTML_Design_System_V1.0.md)

出刊遇到超时或限流，先采用已核验并缓存的同一文件；每日一图还可换用另一幅已核验藏品，同时更新图注、出处和替代文本。若候选均缺许可、解码失败或画面与正文不符，该期省去图片，改留作品文字与官方链接。游戏专文缺图时保留正文分析。以上为编辑和打包方案，本次只验证来源与样图，未部署自动采集。
