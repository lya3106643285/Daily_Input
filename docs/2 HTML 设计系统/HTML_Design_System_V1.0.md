## 基础组件校样的刊头与阅读顺序

[主模板](../../templates/issue.html.j2)依次排刊名、期次日期和首栏。刊名用 h1，日期用 time。首页直接开始阅读。栏目 h2 显示原名与独立文章篇数，导语在栏题下方。每篇以 article 包裹，h3 保留原题，h4 用于文内分节。换篇有细线和上下留白，换节仅用弱标题。

[内容组件](../../templates/components/content.html.j2)按原稿体裁放置来源。新闻摘要在题下逐条列出，讲解综述在篇末列出文章级来源。文章可带摘要。调用方将文章或小节的第一个正文段传为 first=true，题下摘要、出处和插图均不占用首段位置。文章的 lang 取自原稿，中文节首缩进 2em。

## 字体与版心

[版式样式](../../templates/css/publication.css)沿用定稿的本机无衬线字体。正文依次尝试苹方、微软雅黑、Noto Sans CJK SC 和系统 sans-serif，缺字时由系统按字形回退。代码依次采用 ui-monospace、Menlo、Consolas、monospace。无需下载字体。

| 元素 | 字号与排法 |
|---|---|
| 正文 | 20 px，常规字重，31 px 行高，段后 14 px，起始侧对齐 |
| 刊名 / 日期 | 18 / 15 px |
| 栏题 / 篇题 / 弱标题 | 20 px / 随视口在 29–41 px 间变化 / 21 px |
| 图表说明 / 材料出处 | 16 px 半粗 / 13 px 常规 |

默认根字号 16 px 时，版心最大 736 px，两侧各留至少 32 px，窄于约 400 px 时各留 16 px。iPad 横屏继续单栏居中。媒体占版心的 84%，视口不超过 480 px 时占 90%。长代码和宽表分别在自身区域内横向滚动。

## 图片由哪个环节负责

| 环节 | 交付内容 | 当前状态 |
|---|---|---|
| 选题与原稿 | 选择能支持正文的图，核对使用条件，提交随期图片、引用位置、替代文本、图注与出处 | [游戏和每日好图的来源调研](图片来源调研.md)已完成。正式试排的历史稿仅提供了文字和链接 |
| 出版引擎 | 按原稿引用找到本期图片，缩放压缩、内嵌，再把生成的图片组件放回正文对应位置 | 待阶段 3 接入 |
| HTML 模板 | 在文章中按版心宽度显示完整图片，关联图注与出处 | 已用本地 PNG 通过正式整期模板渲染，核对了内嵌字节、替代文本、图注与出处 |
| 成品检查 | 对照原稿检查应有图片，在断网状态确认图片能解码，并检查附件在 iPad 上的显示 | 基础组件校样已有离线解码记录；含真实游戏或馆藏配图的整期附件待验证 |

核对两份 HTML：10 月 31 日整期试排含 0 张内嵌图片，基础组件校样含 1 张内嵌图。前者可用于检查版式和文章来源位置，后者可用于核对图片呈现。

## 材料与证据

[媒体组件](../../templates/components/media.html.j2)以 figure 关联本体、说明、出处与可选本地摘录。图表说明置顶，图片保留替代文本，表头注明列关联。代码语言与可选说明同排，引文保留原段落。各材料的出处逐条右对齐。可核对的本地摘录由出处链接展开，返回链接指回材料。公开出处使用原稿链接。稳定 ID 按 1.7 取自当期清单。

## 单文件封装与模板调用

以 UTF-8 写入 Daily_Input_YYYY-MM-DD.html。主模板先内嵌版式，再内嵌[已验收的主题](../../templates/css/theme.css)。将随期 PNG、JPEG 或 WebP 的完整字节按其实际 MIME 类型编码为 data URI 后传给图片组件。CSS、图像、代码和摘录全部随文件交付；外部来源在读者点击时联网访问。

[可渲染的示范稿](示范稿.html.j2)给出了组件调用顺序。Jinja2 的模板搜索目录为本规范所在目录和项目 templates 目录，开启 autoescape=True 与 StrictUndefined。渲染示范稿时传入 lang、title、ISO 日期 date，以及由 [1.6 原图](<../1.6 媒体内容协议/assets/io-total.png>) 编码的 chart_uri。正式渲染时校验体裁、资源、表格列数及清单 ID；文本交给模板转义。富文本只接受出版程序从已校验的段落和链接生成的 HTML。示范稿内已写定的四个出处链接展示这种输出。
