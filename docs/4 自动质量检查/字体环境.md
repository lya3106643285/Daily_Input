# 固定字体与视觉 QA 环境

用户于 2026-11-07 选择字体实验版。正式出版 CSS 的正文顺序为
`"DejaVu Sans", "Maple Mono NF CN", sans-serif`。
正式样式生成的六个视口截图与用户审阅的字体实验截图逐像素一致。

## 已锁定的依赖

- Python：conda 环境 `daily-input`，由根目录 `environment.yml` 管理。
- Playwright：1.62.0；当前 Chromium：151.0.7922.34（缓存修订 1234）。
- DejaVu Sans / DejaVu Sans Mono：2.37。
- Maple Mono NF CN：7.900，对应官方 v7.9 发布系列。
- fontconfig：2.15.0；Ubuntu libfontconfig1：2.15.0-1.1ubuntu2。
- Ubuntu libfreetype6：2.13.2+dfsg-1ubuntu0.2。

`config/fonts.lock.json` 记录 22 个原版字体文件的名称、内部版本及 SHA-256。
QA 启动浏览器前逐个校验 fontconfig 实际匹配的文件。缺失、同名替换或哈希不同都会失败。
新基线还记录字体锁哈希、Playwright、Chromium、架构、fontconfig 与 FreeType 版本；
普通比较发现环境变化会阻断，不会自动批准新环境。

## 安装与校验

在项目根目录运行：

```bash
source ~/miniconda3/etc/profile.d/conda.sh
conda env create -f environment.yml
conda activate daily-input
python -m playwright install chromium
# 系统依赖安装需要用户授权，并在本机终端输入 sudo 密码
python -m playwright install-deps chromium
python -m publisher.fonts verify
python -m pip check
```

当前机器已安装匹配的字体，不需要重新安装。
在新机器上，从官方 [Maple Mono v7.9](https://github.com/subframe7536/maple-font/releases/tag/v7.9)
获取 NF-CN 原版字体，并准备与锁文件匹配的 DejaVu 2.37 文件。
版本名称相同不代表文件必然相同，应以锁定哈希为准。
对已取得的字体目录，可显式执行用户级安装：

```bash
python -m publisher.fonts install \
  --source-dir /path/to/MapleMonoNFCN \
  --source-dir /path/to/dejavu
python -m publisher.fonts verify
```

此工具不下载、不使用 sudo；先校验全部字体，再复制到用户的
`$XDG_DATA_HOME/fonts/daily-input`（默认 `~/.local/share/fonts/daily-input`）
并刷新 fontconfig。它拒绝覆盖目标目录中不同版本的同名字体。
未提供完整匹配字体时，在复制前失败。安装行为只有在用户显式执行 install 时发生；
QA 的 verify 不写入字体目录。

Maple Mono 的 SIL OFL 1.1 原文和 DejaVu 的随附许可保存在
`config/font-licenses/`，与锁文件一同保留。
字体文件本身未加入仓库；许可和来源资料见
[Maple 项目](https://github.com/subframe7536/maple-font)、
[DejaVu 许可](https://dejavu-fonts.github.io/License.html)。

## 适用范围

这是 Linux Chromium 的固定 QA 字体环境和视口模拟。
HTML 使用系统字体栈，未内嵌字体文件；未安装对应字体的阅读设备仍会按 CSS 回退。
因此，当前验收保证该 QA 环境复现所选效果，
不等同于真实 iPad Safari、Gmail 预览或所有阅读设备的字体完全一致。
如果需要跨设备同字形，应另行实现带许可保留的字体子集内嵌。
