# 媒体内容协议 V1.0（定稿）

适用范围为 1.5 的 Markdown 正文内部。模板从原稿读取材料、说明和出处，分别呈现。原稿及配图可在[媒体标记示例](媒体标记示例.md)中查看；[离线 HTML 样张](媒体试读.html)演示同一份材料的阅读效果。

## 一个材料块怎样组成

先写材料本体；图、表、代码随后写说明，引文直接接出处。最后写一段或多段 `材料出处：…`。各块用空行隔开。出处归属紧邻的这一项，遇到正文、新材料或标题即结束；同一句说明同时适用于两项材料时，分别写明。只在普通段落开头识别这些字段，围栏内的同名文字按代码保留。中文和英文稿件沿用同一组字段名。

| 材料 | Markdown 本体 | 说明与呈现 |
|---|---|---|
| 图片、图表 | 独立成段的 `![替代文本](assets/文件名.png)` | 必填 `图注：…`。图注置于底板上方靠左，出处置于底板下方靠右。替代文本传达图像内容，图注说明读图条件或数据含义。 |
| 表格 | 带表头和分隔行的管道表格，每行列数一致 | 必填 `表注：…`。表注在表格底板上方靠左，表头与数据保持关联；数字列可在分隔行标记右对齐。单元格中的字面竖线写成 `\|`。 |
| 代码 | 围栏代码块，起始围栏必填语言名；纯文本可用 `text` | 可用 `代码说明：…`。原样保留空白、换行及特殊字符，仅展示。说明与语言名合排在代码头栏，出处在块外右下。 |
| 直接引文 | 行首 `> `，同一引文的多段之间用单独的 `>` 行连接 | 引文置于宽竖线引出的浅紫底板，保留原文分段，省去引文说明。出处在引用块外，写明作者或机构、作品、页码或章节等定位信息。转述写普通正文。 |

## 两种来源各归其位

`来源说明：` 属于整篇文章，按 1.5 规则集中写在文章标题后的体裁字段下。出版时，新闻摘要的来源置于题下，讲解综述有独立的文章级出处时置于篇末。若材料旁已完整交代依据、篇末只会重复相同出处，则省略重复的“来源与说明”。`材料出处：` 只属于一张图、一张表、一段代码或一条引文，排在对应材料旁。读者就地看到材料的作者、作品或数据集、适用范围，以及可用的原始链接。原稿提供的署名、版本、许可或改绘说明随该材料保留。构造数据和本项目自制材料直接注明性质；稿件缺资料时记“待补”，进入校对。

## 模块边界与文字层级

已确认配色：材料底板 #F5F1FD 与页面 #F7F8FF 的 sRGB 相对亮度对比度约为 1.05∶1。柱条与竖线沿用 #C7A6FF。自制柱状图采用透明背景，图内显示同一材料底色。

图片、表格、代码、引文共用一条样式规则：材料本体左缘为 6 px 实线，其余三边开放。代码头栏与内容用留白分隔。四类材料均居中，占正文宽度的 84%；视口不超过 480 px 时用 90%。说明、材料本体和出处共用收窄后的左右边线。
- 图片：说明位于底板左上方。柱状图按标签、柱条与数值的实际范围紧凑设定画布，底板内仅留 4 px 衬距。
- 表格：说明在底板左上方。表格使用与引文相同的 6 px 紫色左边线和浅紫底，省去四周细框与单元格横线；表头字重、列对齐和行间距帮助读数。
- 代码：按 Markdown 围栏样式显示，代码区顶部标出围栏声明的语言（如 `python` 显示为 Python），下方用等宽字体保留缩进、换行和局部横向滚动。有说明时与语言名放在同一头栏，窄屏允许在栏内折行。
- 引文：宽竖线引出浅紫底板，板内仅排引文原文。四类材料的出处链接统一在下方靠右。

正文 20 px，模块说明 16 px 半粗，材料出处 13 px 常规。长出处自然换行并保持右对齐。原稿沿用上文的材料优先写法，由出版模板调整阅读顺序。

出处显示可读、带下划线的链接。公开材料直达对应原始资料；项目内部材料可在成品中内嵌注明篇名、章节的原文摘录，并以页内链接定位。无可核实的链接或摘录时标记待补。样张的四个出处链接在各自材料旁按需显示原文摘录，支持离线查看。

## 文件与显示

- 源图采用随期归档的 PNG、JPEG 或 WebP，放在本期 `assets/` 下。原稿相对路径、原图和 manifest 中的媒体条目应对应；外部来源链接与图像文件分别保存。发布时将图片嵌入 HTML，在无网状态可直接阅读。正文链接仍可指向外部资料。
- 图片按原比例缩放至版心以内。表格按行向下展开，过宽时只让表格所在区域横向滚动；代码长行采用相同的局部滚动方式。正文继续使用 1.3 定稿参数。图注、表注、出处和引用块单独排版，节首缩进规则套用于正文。
- 表格、代码和引用分别使用语义化的 table、pre/code、blockquote 元素。来源行用文本或可读的链接名，图片使用 alt。页面保持静态。

## 交稿检查

逐篇检查图片可读且路径落在本期资产目录内、替代文本与必填说明齐备、引用归属明确、表格列数一致、代码围栏闭合。游离的图注、类型不匹配的说明或缺失的材料出处应指出原稿位置。资源缺失时保留原稿并退回校对。此处确定标记和显示约定，后续 1.7 再确定稳定 ID 与锚点。
